The AI Leveling Guide

Five levels that show what AI can do, and how to move up.

L1 → L5 · more leverage with every step
WHY THIS EXISTS
Most people use AI.
Far fewer get real leverage from it. And most do not know how to get from basic use to something that changes how they work. This guide is meant to make that path visible.

What changes at each level
L1 answers a question. L2 finishes a task. L3 fixes the method so it runs the same way every time. L4 grounds AI in a body of knowledge it reasons over. L5 connects agents into a working system.
Where each level tends to fail
L1 fluent answer mistaken for a correct one. L2 weak setup or shallow review. L3 the method goes stale or drifts. L4 messy, incomplete, or outdated knowledge. L5 broken handoffs, monitoring, or recovery.
The Five Levels/Level 1
04

L1: Chat — Ask a question, get an answer

The simplest way to use AI. You type what you want, AI gives you something back, and you decide what to do with it.

Most people live here. One question in, one answer out, maybe a follow-up or two to clean it up. No tools, no setup, no integrations. Just you, the chat box, and whatever you're stuck on.

  • A back-and-forth conversation. You ask, AI answers, you iterate if needed
  • AI is often right, but sometimes confidently wrong. Part of L1 is sensing which one you're getting
  • Works across writing, analysis, research, and code. Anywhere a fast first draft beats a blank page
How to think about it
The skill at L1 isn't prompting. It's judgment. AI will give you a first draft on almost anything. Your job is deciding when to use it, when to push back, and when the confident answer is wrong. Get that right and L1 is enough for a lot of your day.

The Five Levels/Level 2
05

L2: Agent — Give AI a goal, let it do the work

Instead of asking a question, you hand AI a job. It runs the steps on its own and returns a finished result.

Your work moves out of the doing seat. You frame the goal, set the rules, and review the result. The agent owns everything in between.

  • The unit of work is a goal, not a task. "Build the dashboard," not "help me write the SQL"
  • The agent uses tools, makes decisions, and tries multiple approaches. You only see the result
  • When it fails, you read the trace and fix the setup. You don't redo the work yourself
How to think about it
A bad L2 result is usually a setup problem. Fix the framing or the guardrails. Do not jump back in and do the work yourself.

The Five Levels/Level 3
06

L3: Skills — Lock in the right way to do it

The method is fixed. Same inputs, same steps, same checks, same format, every time.

Your job stops being "run it well this time" and starts being "own the method itself." You take the version that works and write it down, so the next run can't drift from it.

  • A Skill is a procedure, not a prompt. Defined inputs, outputs, steps, and checks, version-controlled like code
  • Reach for one when the same ask keeps repeating and the results keep varying between runs
  • The procedure becomes the asset. Any single run stops being where the value lives
How to think about it
L3 is consistency, not cleverness. A Skill you trust beats ten prompts you keep tweaking. What you're relying on is the method itself, not your wording today.

The Five Levels/Level 4
07

L4: Knowledge — The library AI reasons against

AI pulls in the relevant pieces from internal data, past decisions, rules, and patterns, then reasons over them before answering. The method varies. The knowledge is what stays fixed.

At L3 you wrote down one method. At L4 you stop pretending one exists. Your job moves from authoring procedures to curating the library AI reasons against.

  • The answer comes from retrieval plus reasoning. Not a single prompt, not a fixed procedure
  • Reach for it when there's no one right method. The right move depends on which rules, patterns, or data fit the situation
  • One knowledge base powers many Skills, agents, and teammates. Shared infrastructure, not a personal note pile
How to think about it
Think slide-building: dozens of patterns, chart rules, and conventions. The right combination depends on the data, the audience, and the story. No single Skill can hold that. The knowledge base can.

The Five Levels/Level 5
08

L5: Orchestration — Connect agents into a working system

No single agent does the whole job. The work is in the handoffs. How agents pass work, what happens when one breaks, and how the whole thing scales once the wiring works.

Your job isn't building one more agent. It's designing how they coordinate, and what the system does when one of them fails, stalls, or returns something wrong.

  • Multiple agents pass work between each other, and to humans when the system says they're needed
  • The hard part is the weird cases: timeouts, bad inputs, partial failures, contradictions between agents
  • You're designing routing, monitoring, fallbacks, and recovery. Not what any single agent says
How to think about it
L5 isn't more agents. It's less you. The system catches errors, retries, and escalates on its own. Get the wiring right and the same orchestration that handles one task handles a thousand.

Proof of Concept/Made with AI
09

This guide was built with AI

Every section (copy, visuals, interactive demos) was built using the framework you just saw. All five levels were used in the process.
L1Chat
Shaped the copy
Headlines, bullets, and callouts were iterated in conversation. "Too share-focused" → rewrite. "Knowledge is more than patterns" → rewrite. The narrative got sharpened line by line.
L2Agent
Built the demos
Each interactive mockup (iPhone chat, auto-building dashboard, knowledge graph, orchestration tree) was handed off as a goal. The agent wrote the code, ran the page, and iterated until it worked.
L3Skills
Locked in the design
A guide-building Skill encoded the design pattern: layouts, typography, colors, structure. The design language wasn't rebuilt per section. The Skill applied it the same way each time.
L4Knowledge
Grounded the patterns
The Skill didn't guess. It reasoned against a knowledge layer of page patterns, chart rules, and design conventions. The same library this guide is built on.
L5Orchestration
Managed the QC loop
After each build step, the agent screenshotted the output, compared it to intent, and caught issues like blurry charts, broken hovers, or a dark background that should've had orange, then looped back to fix. Same monitor → detect → fix loop as a multi-agent system, inside one.

The AI Leveling Guide/In Closing

In closing

Going further with AI gets easier when the path is visible.

L1 gets you unstuck. L2 gets work done. L3 fixes the method. L4 grounds AI in a body of knowledge. L5 turns it all into a system. See what's possible. Know what to do next.
